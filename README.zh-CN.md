# Folder Spaces

将任意文件夹变成 Obsidian 中独立且可停靠的文件管理器工作空间，让你一次专注于单个上下文。

语言：[English](README.md) | [繁體中文](README.zh-TW.md) | 简体中文

仅支持桌面端 (Desktop only)。

## 为什么需要 Folder Spaces？

Obsidian 的默认文件管理器会一次显示整个 Vault。当 Vault 成长为多个项目、主题与归档文件夹时，文件管理器会变成一张拥挤的地图——即使你只在乎其中一个文件夹，所有文件夹仍同时争夺你的注意力。

Folder Spaces 让你将任意文件夹抽离成独立的 scoped 文件管理器，只看到当前正在处理的上下文：

- 🎯 **一次只专注一个上下文** — 右键点击任意文件夹，即可将其作为独立的文件树打开。无关的文件夹从视野中消失，只剩下你在乎的项目、主题或任务。你同时享有单一 Vault 的优势（跨所有内容的链接、搜索与标签），又能在视觉上隔离的工作空间中专注工作。
- 🧹 **扁平视图 (Flat View)** — 一键将文件夹树压平为干净的单一层级列表。每个子文件夹成为一个标注相对路径的行，让你一眼扫过整个结构，无需逐层展开。
- 🪟 **无干扰的新窗口** — 在独立弹出窗口中打开 Folder Space，将任务与主工作区的侧边栏、标签页分隔开来。在干净的窗口中工作，免去视觉干扰，也可放到副显示器使用。
- 🔗 **与 Window Spaces 搭配** — 搭配 [Window Spaces](https://github.com/edwardsayer/obsidian-window-spaces) 保存与还原这些布局。两者配合可将 Obsidian 打造成 **单库、多项目、多主题的工作空间**：一个 Vault、多个独立的专注窗口，各自围绕自己的文件夹上下文排列。

## 主要功能

- **文件夹右键菜单集成**：右键点击默认文件管理器中的任意文件夹，可通过 `Folder Spaces` 菜单打开：
  - 在默认位置打开
  - 在左侧边栏打开
  - 在右侧边栏打开
  - 在编辑区打开
  - 在新窗口打开
- **完全独立的文件夹视图**：打开专属的 Folder Space 视图标签页，完全不影响 Obsidian 原生的全库文件管理器。
- **树状与扁平视图模式**：每个文件夹可独立切换嵌套树状与干净的扁平列表，并单独记住各文件夹的视图模式。
- **工作区布局恢复**：重启 Obsidian 后自动恢复已打开的 Folder Space 标签页。
- **交互式 Header 工具栏**：
  - 显示当前根目录路径。
  - 点击根目录标题，打开可搜索的文件夹选择器来切换根目录——可用于返回上层文件夹，或直接跳到任意子文件夹。
  - 右键点击标题文字，调用 Obsidian 原生文件夹右键菜单 (`file-menu`)。
  - `视图模式` 按钮：切换当前文件夹的树状／扁平视图。
  - `文件夹图标` 按钮：为当前根文件夹设置自定义图标（覆盖全局图标）。
  - `更多选项` 按钮 (`⋮`)：触发文件夹操作菜单。
  - 重命名根文件夹时自动弹出安全重命名对话框并同步更新工作区。
- **自定义标签页图标**：提供可搜索的图标选择器，轻松设置 Folder Space 标签页图标——可在设置中设置全局图标，也可从 Header 工具栏为每个根文件夹单独设置图标。
- **快速打开**：通过侧边栏功能区图标或 `打开 Folder Space` 命令选择文件夹，并在默认位置打开。
- **弹出窗口感知的打开**：在弹出窗口内执行 `打开 Folder Space` 命令或 `Folder Spaces` 右键子菜单时，新的 Folder Space 会在**同一个弹出窗口**内打开——重用或创建全高左/右侧栏，或打开在弹出窗口的编辑区——而不会跳回主窗口。
- **同窗口搜索**：当 Folder Space 位于弹出窗口时，原生的 *Search in folder* 右键动作会在该弹出窗口内显示搜索结果，而非主窗口。
- **弹出窗口中的侧边栏视图**：在弹出窗口内执行原生侧边栏视图的命令（标签、大纲、反向链接、属性、搜索等），会在**同一个弹出窗口**内打开，并可在 split／标签组之间拖曳。
- **面板不会被取代**：在弹出窗口中，侧边栏面板（backlink、outline、outgoing links、search 等）与 Folder Space explorer 不会被新打开的笔记取代——笔记会打开在先前 active 的笔记标签上，或在其标签组中新建标签；未固定的笔记标签仍保持正常的"打开在当前标签"行为。
- **开发者 Public API**：供第三方插件（如 Window Spaces）集成与联动。

## 使用方式

1. 打开 Obsidian 默认文件管理器。
2. 右键点击任意文件夹。
3. 选择 `Folder Spaces` 并选择打开位置（默认位置、左侧边栏、右侧边栏、编辑区或新窗口）。
4. 在新打开的 Folder Space 标签页中，将该文件夹作为独立树状图进行浏览与操作。点击 Header 工具栏的根目录标题即可通过文件夹选择器切换根目录，并在树状／扁平视图之间切换。

## 使用场景与工作流

把每个 Folder Space 视为一个**专注空间 (Focus Room)**，用于单个项目、主题或工作流程。不必在整个 Vault 中导航，直接走进你需要的文件夹：

- **项目工作区** (`Projects/<name>`)：将 Folder Space 根目录设为当前项目。该项目所有的规格、笔记与资源尽在一棵树中，无关的项目完全不出现在视野中。
- **写作与内容制作** (`Writing/`)：在自己的空间中打开写作文件夹——使用扁平视图即可将所有草稿与笔记以单一干净列表呈现。
- **研究与文献** (`Research/`)：将文献或主题文件夹独立出来，让阅读笔记与来源资料保持在单一专注的上下文。
- **扁平结构扫描**：对深度嵌套的文件夹，切换到扁平视图即可一眼看到所有子文件夹（标注相对路径）与其中的文件。
- **无干扰的深度工作**：在新窗口中打开 Folder Space 并置于副显示器，让任务上下文完全与主工作区分离。
- **单库多项目工作空间**：将 Folder Spaces 与 Window Spaces 结合。每个项目拥有文件夹范围的文件管理器；Window Spaces 保存每个项目的窗口排列，让你随意在项目"房间"之间切换——每个房间都有各自的文件夹上下文与主题。

## 设置选项

- **Folder Space 视图图标**：自定义 Folder Space 标签页所使用的图标。
- **默认文件夹视图**：选择尚未保存单独模式的文件夹使用的视图模式（树状或扁平）。
- **默认打开位置**：选择新 Folder Space 打开的位置——主窗口与弹出窗口可分别设置（左侧边栏、右侧边栏、编辑区或新窗口）。

## 兼容性

- **Obsidian 版本**: `v1.0.0+`
- **支持平台**: 仅限桌面版 (Windows, macOS, Linux)

## 开发者 API (Developer API)

第三方插件可通过以下方式访问 API：

```typescript
const api = app.plugins.plugins["folder-spaces"]?.api;
if (api) {
  const isFolderSpace = api.isFolderSpaceView(leaf);
  const folderPath = api.getFolderPath(leaf);
  const spaces = api.getFolderSpaces();
  await api.openFolderSpace("Projects/Active", "left-sidebar");
}
```
