# Folder Spaces

将任意文件夹变成 Obsidian 中独立且可停靠的文件管理器工作空间，让你一次专注于单个上下文。

语言：[English](README.md) | [繁體中文](README.zh-TW.md) | 简体中文

仅支持桌面端 (Desktop only)。需要 Obsidian **1.7.2+**。

## 为什么需要 Folder Spaces？

Obsidian 的默认文件管理器会一次显示整个 Vault。当 Vault 成长为多个项目、主题与归档文件夹时，文件管理器会变成一张拥挤的地图——即使你只在乎其中一个文件夹，所有文件夹仍同时争夺你的注意力。

Folder Spaces 让你将任意文件夹抽离成独立的 scoped 文件管理器，只看到当前正在处理的上下文：

- 🎯 **一次只专注一个上下文** — 右键点击任意文件夹，即可将其作为独立的文件树打开。无关的文件夹从视野中消失，只剩下你在乎的项目、主题或任务。你同时享有单一 Vault 的优势（跨所有内容的链接、搜索与标签），又能在视觉上隔离的工作空间中专注工作。
- 🪟 **无干扰的新窗口** — 在独立弹出窗口中打开 Folder Space，将任务与主工作区的侧边栏、标签页分隔开来。在干净的窗口中工作，免去视觉干扰，也可放到副显示器使用。
- 🔗 **与 Window Spaces 搭配** — 搭配 [Window Spaces](https://github.com/edwardsayer/obsidian-window-spaces) 保存与还原这些布局。两者配合可将 Obsidian 打造成 **单库、多项目、多主题的工作空间**：一个 Vault、多个独立的专注窗口，各自围绕自己的文件夹上下文排列。

## 主要功能

### 任意位置打开
- **文件夹右键菜单集成**：右键点击默认文件管理器中的任意文件夹，可通过 `Folder Spaces` 菜单打开：
  - 在默认位置打开
  - 在左侧边栏打开
  - 在右侧边栏打开
  - 在编辑区打开
  - 在新窗口打开
- **快速打开**：通过侧边栏功能区图标或 `打开 Folder Space` 命令搜索文件夹，并在默认位置打开。
- **从弹出窗口内打开**：在弹出窗口内执行命令或右键子菜单，新的 Folder Space 会在**同一个弹出窗口**内打开——重用或创建全高左/右侧栏，或打开在弹出窗口的编辑区——而不会跳回主窗口。
- **同窗口搜索**：当 Folder Space 位于弹出窗口时，原生的 *Search in folder* 动作会在该弹出窗口内显示搜索结果。
- **弹出窗口中的侧边栏视图**：在弹出窗口中打开任何原生侧边栏视图——标签、大纲、反向链接、outgoing links、属性、搜索等——并可在 split／标签组之间拖曳。

### Scoped、独立的树
- **完全独立的文件夹视图**：打开专属的 Folder Space 视图标签页，完全不影响 Obsidian 原生的全库文件管理器。
- **树状与扁平视图模式**：每个文件夹可独立切换嵌套树状与干净的扁平列表。
- **展开层级控制**：展开 1 层、2 层或全部层级——每个文件夹可独立设置。
- **显示内容控制**：显示文件夹、文件或全部项目——每个文件夹可独立设置。
- **视图预设**：六个具名预设，组合视图、展开层级与内容——`Explorer`（标准树状）、`Navigate`（纯文件夹树）、`Columns`（单层文件夹列表）、`Context`（双层文件夹树）、`Contents`（扁平总览）、`Files`（扁平文件列表）。可应用于每个面板，也可在父面板驱动其子面板链时横向应用。
- **过滤与排序**：按路径子字符串过滤，并按名称、修改时间或创建时间排序（升/降序）——每个文件夹可独立设置。
- **工作区布局恢复**：重启 Obsidian 后自动恢复已打开的 Folder Space 标签页。

### 单行 Header 与根目录操作
Folder Space 的 header 是紧凑的单行，并保留原生文件操作：

- 显示当前根目录路径（截断显示，悬停以 tooltip 显示完整路径）。
- **点击根目录标题**：打开可搜索的文件夹选择器——返回上层文件夹，或直接跳到任意子文件夹。
- **右键点击根目录标题**：调用原生文件夹右键菜单 (`file-menu`)——包含新建 note／新建文件夹等完整文件操作。
- **选择子文件夹／返回上层**操作：移动根目录范围。
- **`视图设置` 菜单**：切换树状／扁平、展开层级与内容、预设、过滤、排序、设置自定义文件夹图标、显示／自动显示当前文件、全部折叠／展开。
- **安全重命名**的文件夹重命名对话框。
- **每个文件夹的设置**（视图、层级、内容、排序、图标）会被记住，并在文件夹重命名或移动时自动迁移。

### 多面板级联联动 (Cascading Panel Binding)
将 Folder Space 面板串成 parent → child → grandchild 的级联链，跨面板带动文件夹上下文：

- 在任一 Folder Space（或原生文件管理器）中右键点击文件夹并打开新面板——新面板**自动绑定为来源面板的子面板**。
- **"与父面板文件夹焦点同步"** 开关（默认 ON）会让子面板的文件夹范围跟随父面板的文件夹选择；关闭后子面板范围保持固定。
- **原生文件管理器也可作为父面板**，从其树状驱动已绑定的子面板。
- **无限深度**：子面板也可以再作为父面板打开子面板，焦点沿整条链下传（含循环保护）。绑定关系在重载后仍保留。
- **自适应父面板模式**：有子面板附着时，父面板可自动切换到纯文件夹导航预设，让链条呈现"Navigator → Bridge → Terminal"的阅读节奏。

### 面板不会被取代
- 在弹出窗口中，侧边栏面板（backlink、outline、outgoing links、search 等）与 Folder Space explorer **不会被新打开的笔记取代**——笔记会打开在先前 active 的笔记标签上，或在其标签组中新建标签；未固定的笔记标签仍保持正常的"打开在当前标签"行为。

### 兼容性与生态
- **原生文件管理器核心**：Folder Space 重用 Obsidian 原生文件管理器的树状核心，因此拖放、键盘导航、右键菜单与 DOM 扩展都保持可用。
- **第三方文件管理器扩展**：CSS／DOM 装饰与 `data-*` 元素属性通常可通过兼容性桥接带入（事件处理器与内部状态不会复制）。
- **Folder Notes 感知**：可选择在纯文件夹视图中停用文件夹笔记打开，让点击文件夹是导航而非打开笔记。
- **开发者 Public API**：供第三方插件（如 Window Spaces）集成的稳定公开 API——见 [doc/api.md](doc/api.md)。

## 使用方式

1. 打开 Obsidian 默认文件管理器。
2. 右键点击任意文件夹。
3. 选择 `Folder Spaces` 并选择打开位置（默认位置、左侧边栏、右侧边栏、编辑区或新窗口）。
4. 在新打开的 Folder Space 标签页中浏览与操作。点击 Header 的根目录标题可通过文件夹选择器切换根目录、切换树状／扁平视图，或应用预设。

## 使用场景与工作流

把每个 Folder Space 视为一个**专注空间 (Focus Room)**，用于单个项目、主题或工作流程：

- **项目工作区** (`Projects/<name>`)：将 Folder Space 根目录设为当前项目。该项目所有的规格、笔记与资源尽在一棵树中，无关的项目完全不出现在视野中。
- **写作与内容制作** (`Writing/`)：在自己的空间中打开写作文件夹——使用 `Contents`／`Files` 预设或扁平视图将所有草稿以干净列表呈现。
- **研究与文献** (`Research/`)：将文献或主题文件夹独立出来，让阅读笔记与来源资料保持在单一专注的上下文。
- **扁平结构扫描**：对深度嵌套的文件夹，切换到扁平视图即可一眼看到所有子文件夹（标注相对路径）与其中的文件。
- **多面板级联**：串起 `Navigate`（或 `Columns`）纯文件夹导航器 → `Context` 中转 → `Contents`／`Files` 终端，逐步下钻大型结构，同时让每个层级保持专注。
- **无干扰的深度工作**：在新窗口中打开 Folder Space 并置于副显示器，让任务上下文完全与主工作区分离。
- **单库多项目工作空间**：将 Folder Spaces 与 Window Spaces 结合。每个项目拥有文件夹范围的文件管理器与保存的窗口排列，像项目"房间"一样切换。

## 设置选项

- **常规**
  - **显示功能区图标**：在侧边栏功能区显示 Folder Space 图标以打开文件夹选择器。
  - **默认打开位置**：新 Folder Space 打开的位置——**主窗口**与**弹出窗口**可分别设置（左侧边栏、右侧边栏、编辑区或新窗口）。
- **显示选项**
  - **默认文件夹视图**：尚未保存个别模式的文件夹使用的视图模式（树状或扁平）。
  - **默认展开层级**：1 层、2 层或全部层级。
  - **默认内容**：文件夹、文件或全部。
  - **视图预设**：新面板的预设、子面板的预设、自动应用子面板预设、自适应父面板模式，与父面板导航预设。
- **与父面板同步**：新子面板默认是否与父面板同步文件夹焦点，同窗口与新窗口可分别设置。
- **Folder Notes**：在纯文件夹视图中停用文件夹笔记打开。

## 兼容性

- **Obsidian 版本**: `1.7.2+`
- **支持平台**: 仅限桌面版 (Windows, macOS, Linux)

## 开发者 API (Developer API)

第三方插件可通过以下方式访问 API：

```typescript
const api = app.plugins.plugins["folder-spaces"]?.api;
if (api) {
  const isFolderSpace = api.isFolderSpaceView(leaf);
  const folderPath = api.getFolderPath(leaf);
  const spaces = api.getFolderSpaces();
  await api.openFolderSpace("Projects/Active", "left-sidebar");
}
```

完整的 API 参考见 [doc/api.md](doc/api.md)。
